照片筛查 v1.1
Windows 本地 JPEG 重复照片筛查工具

一、运行
双击“照片筛查.exe”。无需安装 Python，无需联网或上传照片。
面向 Windows 10 / 11，使用系统的 .NET Framework 4.x。
程序为未签名的本地构建版本；没有安装程序。

二、推荐流程
1. 选择包含照片的文件夹，或把文件夹拖入首页，按需启用“包含子文件夹”。
2. 保持“严格相似（推荐）”，点击“开始扫描”。
3. 左侧选择候选组，右侧查看照片。点击“大图对照”或双击缩略图，
   与参考图并排查看大图。顶部显示已分析照片、候选组数和已勾选文件大小。
   大图窗口可切换“原始像素（滚动查看）”。
4. 可以“导出候选副本”，程序会在所选位置创建新的目录，按组复制照片，
   并保存“原始路径对照.csv”。此操作不移动、不删除原始照片。
   导出的是所有候选组，不只导出勾选项。
5. 手动勾选不需要的照片，然后点击“移入回收站”。勾选可以跨组保留。
   删除前弹出确认，每组必须至少保留一张。

三、匹配模式
仅完全重复：SHA-256 文件内容相同。重新压缩或修改元数据后通常不再视为相同。
严格相似：默认档，综合感知哈希、差异哈希、宽高比和平均颜色。
一般相似 / 宽松相似：允许更多差异，也可能把不同照片归为一组。
支持 .jpg、.jpeg，扩展名不区分大小写；读取时处理常见 EXIF 方向信息。
每组成员与参考图直接匹配，不依赖逐张相似的连锁关系。
“特征差异”是感知哈希位差，不是准确率，也不是相似百分比。

四、保留与删除
程序不会自动勾选、自动删除或后台扫描。
“勾选本组其余照片”会按像素数、再按文件大小保留一张，其余勾选；
这只是便于操作，不代表算法判断了画质。仍需检查曝光、清晰度、人物表情等。
每次删除前检查待删照片及至少一张保留照片的文件时间、大小和 SHA-256。
扫描后有变化或无法读取的文件会跳过，详情见“扫描日志”。
程序调用 Windows 回收功能，并保留 Windows 自身的确认提示。
某些网络位置、外置设备或回收站设置可能无法回收；
如果 Windows 提示需要永久删除，请取消，改用“导出候选副本”进行核对。
移入回收站后，可在 Windows 回收站中还原。
不要在筛查过程中同时用其他软件改动、移动这些照片。

五、范围与限制
这是辅助人工筛查的工具，相似不等于重复。
大幅裁剪、旋转、重度滤镜、拼图可能漏检；内容很简单的画面可能误报。
只筛查 JPEG/JPG，不处理 HEIC、RAW、PNG、视频。
包含子文件夹时跳过重解析点（例如目录链接），避免循环和重复遍历。
损坏图片、读取失败和部分路径问题会记录到扫描日志。
每页显示 24 张候选，更多照片可翻页；同页照片可滚动查看。
照片卡片随窗口宽度调整列数；窗口较小时，滚动可查看卡片下方按钮。
扫描在后台执行，可取消；导出副本需等待完成，失败时已复制的文件会保留。
导出副本会占用额外磁盘空间；下一次扫描建议不要包含导出的副本目录。

六、验证信息
已在本机通过 JPEG 压缩/缩放匹配、完全重复、不同画面排除、
中文路径、大小写扩展名、递归扫描、损坏文件、取消、文件变更检测、
副本导出和窗口渲染等检查。
未对用户的实际照片执行删除；具体设备的回收行为取决于 Windows。

七、源代码
“照片筛查-源代码.zip”包含 C# 源代码、构建脚本和验证程序。
源代码可用于后续修改；日常使用只需 EXE 文件。
